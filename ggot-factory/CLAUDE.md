# GGOT Factory Desk 개발 지시
사용자는 Tony와 金彤. 아이폰 Safari, Windows 데스크톱. 박람회 현장 빠른 입력 우선. 설명만 하지 말고 이 프로젝트를 실행하고 실제로 개선하라.

## 기존 구현
무의존성 ES modules + Node 정적 서버, IndexedDB 기기별 저장(v2: 메타/사진 분리), PWA(서비스워커 cache-first), 한/중 UI, 휴지통 삭제, 버전 벡터 기반 파일 교환 동기화(서버 없음). npm start, npm test, npm run e2e(Playwright). 외부 API 키 없음. GitHub Pages 수동 배포 워크플로 준비됨(실행은 사용자가). 실제 배포 실행·아이폰 실기기 검증·공동 로그인은 미완료다. 검증 현황은 docs/VERIFICATION.md. 구현되지 않은 기능을 완료로 표시하지 않는다.

## 절대 보존할 흐름
새 업체 → 이름 또는 위챗 QR/명함 사진 → 제품별 체크 → 참고사진 → 완료/다음 업체 → 자동 비교표.
회사명 모르면 임시명. QR 사진은 저장만 하며 이름 자동 추출 또는 친구 추가를 했다고 표시하지 않는다. 실제 친구 추가는 위챗. 한 공장 여러 담당자·제품·견적·샘플을 최종 모델에서 지원.
버튼 44px 이상, 16px 입력 폰트, 기타 텍스트, 미응답은 미확인. 질문은 한국어/중국어. 답변과 증빙 단계를 분리. 체크가 효능 입증 또는 규제 승인이라는 의미가 아님.
브랜드 라임 #D4FF3F / 보라 #7B4DFF / 흰색. 모바일 세로 카드, 데스크톱 비교표.

## 우선 작업 순서
1. README와 docs/SPEC.md를 읽고 npm test 및 실행. 로컬 변경 보존.
2. 브라우저 검증: 등록→리로드 유지→다제품→사진→백업/새 브라우저 복원→비교→CSV. 390px/1440px.
3. IndexedDB 저장 실패 때 성공으로 진행하지 않게 처리. 현재 persist는 오류 상태만 보여주므로, 완료/다음/가져오기는 실패를 전파하도록 개선. 저장 큐와 사진 처리 중 화면 이동의 안전성 확인.
4. 사진 압축본 저장을 명시하고 원본 보관 옵션, 사진 삭제 확인, 확대보기, 업체 미연결 사진함, 사진 메모 편집 개선.
5. 한국어/중국어 UI 전환 및 중국어 문의 복사. 답변/증빙 버튼도 번역.
6. PWA manifest, 아이콘, service worker를 구현하여 HTTPS에서 최초 로드 후 오프라인 앱 시작 검증. 현재는 서버 연결 없이 새로고침할 수 있다고 주장하지 말 것.
7. 실사용 전 HTTPS 배포 경로를 제시하고 아이폰 카메라/사진/파일 다운로드·복원을 실제 확인. localhost는 다른 기기에서 연결되지 않는다. LAN 주소는 테스트용. iPhone은 동일 URL/브라우저 유지.
8. 시간이 부족하면 공동 계정 연동은 미룬다. 데이터는 양쪽 기기에만 존재하고 자동 동기화되지 않는다는 표시 유지.

## 후속 공동관리
인증된 Tony/金彤만 접근하는 workspace 기반 backend adapter 도입. Supabase 또는 동등 서비스는 사용자가 선택하고 자격증명 제공 후 연결. 클라이언트에 service-role 키 금지. 서버 인가/RLS, 비공개 사진 저장소, 로그아웃, 동기화 큐, 충돌 해결, 오프라인 복구 테스트 필수. 중국 본토와 홍콩 양쪽 실기기 연결 성능을 측정하고 서비스 선택. 실측 없는 접속 보장 금지.

## 자료/보안
메모는 textContent/escaping, 업로드 파일 검증, CSV 수식 주입 방어. 위챗 QR·연락처·견적은 개인 및 사업정보. 테스트 데이터는 합성만. 자동 공유/공개 배포/외부 AI 업로드 금지. OCR은 별도 동의와 로컬/서버 경계 설명 후 추가.
