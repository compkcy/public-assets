# Claude Code에 붙여넣을 첫 지시

이 폴더의 CLAUDE.md, README.md, docs/SPEC.md를 읽고 GGOT Factory Desk를 이어서 개발해줘.
먼저 기존 프로젝트를 실행하고 테스트한 다음, 아이폰 현장 사용에 필요한 저장 안정성·사진 입력·업체별 체크리스트·비교표를 검증해줘.
사용자는 Tony와 金彤이고, 아이폰과 Windows에서 쓸 거야. 위챗 QR 또는 회사명으로 업체를 순차 등록하고, 제품별 질문을 버튼으로 체크하고, 사진을 찍은 뒤 다음 업체로 넘어가야 해.
선크림뿐 아니라 미스트·세럼·젤·크림·버블·마스크팩, 진정·보습·쿨링·장벽 질문을 지원해줘.
기존 데이터를 보존하고, 연결이 오래 걸리면 공동 로그인은 미뤄. 우선 기기별 저장과 사진 포함 백업/병합을 완성해줘.
모바일/데스크톱 화면을 실제 테스트하고 PWA·HTTPS 배포 준비까지 진행해줘. 배포나 외부 서비스 연결 전 필요한 설정을 알려줘. 완료됐다는 설명 대신 작동하는 코드와 검증 결과를 남겨줘.
