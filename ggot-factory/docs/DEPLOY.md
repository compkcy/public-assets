# 아이폰 설치 · 중국 현장 사용 가이드 (VPN 없이)

## 핵심 원리
- 이 앱은 **설치 후 인터넷이 전혀 필요 없는** 웹앱(PWA)입니다. 기록·사진은 아이폰 안(IndexedDB)에만 저장되고 서버로 보내지 않습니다.
- 그래서 중국에서 VPN이 없어도 **이미 설치된 앱은** 비행기 모드에서도 열리고 입력·사진·백업이 됩니다 (Chromium 자동 테스트로 확인, 아이폰 실기기는 아래 체크리스트로 직접 확인 필요).
- 인터넷이 필요한 순간은 **처음 설치할 때**와 **새 버전 받을 때**뿐입니다. 이 두 가지는 **한국에서 출국 전에** 끝내세요.
- 중국 본토에서 github.io 접속은 보장할 수 없습니다(측정 안 함). 한국 유심 로밍은 보통 한국을 거쳐 연결되어 접속되는 경우가 많지만 이것도 실측하지 않았습니다. 현장에서 설치/업데이트에 의존하지 마세요.

## "나만 볼 수 있나요?"
- 배포 주소(예: `https://compkcy.github.io/public-assets/`)는 **빈 앱 프로그램**만 내려줍니다. 누가 같은 주소를 열어도 자기 기기의 빈 앱이 보일 뿐, Tony·金彤의 기록은 보이지 않습니다.
- 로그인·서버·클라우드 DB가 없으므로 남이 원격으로 볼 경로가 없습니다. 대신 **아이폰을 잃어버리거나 앱을 지우면 기록도 사라지므로** 백업 파일이 유일한 복구 수단입니다.
- 이 저장소(`compkcy/public-assets`)는 **공개 저장소**입니다. 앱 코드가 공개되는 것은 문제가 없지만, **백업 JSON·CSV·실제 사진을 이 저장소에 올리지 마세요.**
- 주소 자체를 숨기고 싶다면 비공개 저장소 + 유료 GitHub 플랜이 필요합니다. 데이터 보호에는 영향이 없어 지금은 권장하지 않습니다.

## 1. 배포 (PC에서 1회, 약 5분)
1. 이 브랜치를 `main`에 병합합니다 (워크플로 파일이 기본 브랜치에 있어야 실행 버튼이 보입니다).
2. GitHub 저장소 → **Settings → Pages → Build and deployment → Source: GitHub Actions** 선택.
3. **Actions 탭 → "Deploy GGOT Factory Desk (manual)" → Run workflow** (수동 실행 전용, 자동 공개 배포 없음).
4. 완료되면 주소가 표시됩니다: `https://compkcy.github.io/public-assets/`
   - 게시되는 파일: `index.html, style.css, manifest.webmanifest, sw.js, src/*.js(테스트 제외), icons/` 만. 저장소의 다른 이미지·문서는 게시되지 않습니다.
5. 코드를 고치면 같은 버튼으로 다시 배포합니다. 배포마다 캐시 버전이 자동으로 바뀌어 아이폰 앱에 **[새 버전 준비됨 · 지금 적용]** 줄이 뜹니다.

> 다른 HTTPS 정적 호스팅(Cloudflare Pages, Netlify 등)도 같은 파일을 올리면 됩니다. 중국 본토 서버(알리클라우드 등)는 ICP 비안(备案)이 필요해 이번 일정에는 비현실적입니다.

## 2. 아이폰 설치 (Tony, 金彤 각각, 출국 전)
1. **Safari**(크롬 X)로 배포 주소를 엽니다.
2. 공유 버튼 → **홈 화면에 추가** → 이름 "GGOT Desk".
3. **홈 화면 아이콘으로 앱을 엽니다.** (Safari 탭과 홈 화면 앱은 저장소가 따로입니다. 입력은 홈 화면 앱에서만!)
4. 하단 메뉴 **[상태]** → "오프라인 실행: 준비됨" 확인. "준비 중"이면 앱을 완전히 닫고(앱 전환기에서 위로 밀기) 다시 엽니다.
5. **비행기 모드 켜기** → 앱 완전히 닫기 → 다시 열기 → 열리면 성공.
6. 비행기 모드 상태로 아래 실기기 체크리스트를 한 번 해봅니다.

## 3. 실기기 체크리스트 (아직 미검증 — 꼭 해보세요)
- [ ] 비행기 모드에서 앱 시작 → 새 업체 → 위챗 QR 촬영(카메라가 바로 열림) → 다음 업체
- [ ] 사진 선택(앨범) 여러 장, HEIC 사진도 정상 저장되는지
- [ ] 입력 후 앱 완전 종료 → 재실행 → 기록 유지
- [ ] [백업] → 백업 파일 만들기 → [공유 · 파일에 저장] → "나의 iPhone"에 저장되는지
- [ ] 다른 아이폰으로 **AirDrop**(인터넷 불필요) → 받은 쪽 앱 [백업] → 백업 파일 선택 → 합치기
      (AirDrop "모든 사람"은 10분 제한이 있으니 Tony·金彤 서로 연락처에 저장해 두세요)
- [ ] [중국어 질문 복사] → 위챗에 붙여넣기
- [ ] Windows PC Chrome/Edge에서 같은 주소 → 백업 파일 합치기 → 비교표 → CSV를 Excel로 열기 (한글·중국어 깨짐 없는지)

## 4. Tony ↔ 金彤 동기화 (인터넷 없이)
1. Tony: [백업] → [동기화 파일 만들기] → [공유 · 파일에 저장] → **AirDrop** → 金彤 아이폰
2. 金彤: 받은 파일이 "파일" 앱에 저장되면, GGOT 앱 [백업] → [받은 파일 선택] → 방금 받은 파일
3. 반대로 金彤 → Tony 한 번 더. 이제 두 기기가 같습니다. 하루 1~2번(점심·저녁) 권장.
- 더 최신 기록으로 자동 갱신되고, 휴지통으로 옮긴 업체도 상대에게 전달됩니다.
- 두 사람이 같은 업체를 그 사이에 각각 고쳤다면 덮어쓰지 않고 "(가져온 사본)"이 생깁니다. 비교 후 하나를 휴지통으로.
- 같은 업체를 두 사람이 따로 새로 등록하면 별개 업체로 남습니다. 부스에서는 한 사람이 등록하는 걸 권장.

## 5. 현장 운영 수칙
- 하루 2~3번 [백업] → "파일에 저장"(나의 iPhone). 와이파이가 되면 iCloud Drive에도.
- 홈 화면 앱을 **삭제하지 마세요** (기록이 함께 삭제됨). 설정 → Safari → "방문 기록 및 웹사이트 데이터 지우기"도 금지.
- 아이폰 저장공간을 넉넉히 (사진 1장 약 0.3~0.6MB 압축본. 원본 보관을 켜면 몇 MB씩 늘어남).
- 위챗으로 백업 파일을 보내면 텐센트 서버를 거칩니다. 사업 정보이므로 AirDrop을 우선 사용하세요.
- 저장 실패(빨간 줄)가 뜨면 앱을 닫지 말고 [백업 만들기]부터 하세요.

## 6. 개발/테스트용 (참고)
- PC: `npm start` → http://localhost:5173 (PC에서만 열림)
- 같은 와이파이 아이폰: `http://PC-IP:5173` 은 **HTTPS가 아니어서 오프라인 기능·클립보드가 동작하지 않는** 화면 확인용입니다. 거기서 입력한 기록은 배포 주소 앱과 별개입니다.

## 7. 나중에: 데스크톱 공장관리로 이전
- 지금 백업 JSON(schemaVersion 1)이 이전용 원본 형식입니다. 업체·제품·답변·사진이 모두 들어 있습니다.
- Windows에서는 같은 주소를 Chrome/Edge로 열고 "앱 설치"하면 데스크톱 창으로 쓸 수 있고, 두 사람의 백업을 합쳐 비교표·CSV를 만들 수 있습니다.
- 두 사람 실시간 공동 관리(로그인·동기화)는 CLAUDE.md "후속 공동관리" 단계에서 서비스 선택·중국/홍콩 실측 후 진행합니다.
