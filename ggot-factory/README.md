# GGOT Factory Desk 0.3
중국 박람회 현장에서 아이폰으로 공장·제품 정보를 빠르게 기록하는 오프라인 웹앱(PWA). 이후 데스크톱 공장관리로 확장.

- **VPN 없이 사용**: 출국 전에 홈 화면에 설치하면 인터넷 없이 실행됩니다 → [docs/DEPLOY.md](docs/DEPLOY.md)
- **나만 보는 기록**: 서버·로그인·클라우드 없음. 기록과 사진은 각 기기에만 저장. 자동 동기화 없음(백업 파일로 합치기).

## 실행
```
npm start        # http://localhost:5173 (이 PC에서만)
npm test         # Node 단위·정적 테스트 (외부 패키지 없음)
npm run check    # 구문 검사
npm run e2e      # 브라우저 종단 테스트 (Playwright 필요, 아래 참고)
```
Node 20 이상. `npm install` 불필요. e2e는 Playwright가 설치된 환경에서 `NODE_PATH=$(npm root -g) npm run e2e`.

## 현장 흐름
새 업체(또는 📷 QR·명함 사진부터 등록) → 회사명/임시명 → 제품별 종류·효능 선택 → 질문별 답변+증빙 → 참고 사진 → **완료 · 다음 업체** → 비교표/CSV

## 기능
- 업종: 화장품 OEM·ODM / **용기·패키지** / 기타. 용기 제품은 종류(펌프·스프레이·에어리스·튜브·자·스틱·파우치·마스크팩 파우치·단상자·라벨)·소재·규격과 용기 전용 질문(금형·개모비·소재·호환성·누액·인쇄·AQL·납기 등)
- **신뢰 확인**: 영업집조·생산허가증·자체 공장·인증서·거래 실적·견적 완결·샘플 일치·회신·결제 계좌명을 확인/주의/미확인으로 기록 + 위험 신호 + 판단 근거 메모. 점수·순위 없음 (기준은 docs/SPEC.md '판단 기준')
- 임시 이름 업체 등록, 위챗 QR/명함 사진 보관 (QR 해독·OCR·친구 추가 없음 — 친구 추가는 위챗 앱에서)
- 제품 종류: 선크림·미스트·세럼·젤·크림·버블·마스크팩·기타 / 효능: 진정·보습·쿨링·피부장벽·자외선 차단
- 종류·효능별 한·중 질문 25개, 답변(있음/없음/확인 필요/해당 없음)과 증빙(업체 설명/자료 요청/자료 수령/검토 완료) 분리, 다시 누르면 해제(=미확인), 숨겨진 질문의 답변 보존
- 한국어/中文 화면 전환, **중국어 질문 복사**(미응답 질문 → 위챗 붙여넣기)
- 사진: 긴 변 1800px JPEG 압축본 저장(원본 아님, 원본 보관 옵션), 확대보기, 분류·연결 제품·메모·중요 편집, 삭제 확인, 미연결 사진함
- 저장 안정성: 저장 큐, 실패 시 빨간 경고줄 + [다시 저장]/[백업], **저장 실패 시 다음 업체 이동·업데이트 차단**, 사진 처리 중 이동 시 완료 대기, 앱 백그라운드 전환 시 즉시 저장
- 사진 포함 백업(아이폰 공유 시트 → 파일에 저장/AirDrop, 또는 다운로드), 백업 합치기(기존 기록 덮어쓰기 없음, 충돌은 사본 보존, 같은 파일 재가져오기 중복 없음, 한 트랜잭션으로 기록)
- 제품 단위 비교표: 관심도·작성자·종류·효능·샘플·증빙·검색 필터, 질문 열 추가, 모바일은 카드형, CSV(BOM, 수식 주입 방어). 점수·순위 없음
- PWA: manifest·아이콘·서비스워커(cache-first), 새 버전은 [지금 적용]을 눌렀을 때만 교체
- 상태 화면: 오프라인 준비 여부, 영구 저장 허용, 사용량, 마지막 백업

## 저장 구조
IndexedDB `ggot-factory` v2: `state['suppliers']`(메타데이터), `photos`(압축본/원본), `thumbs`(미리보기).
0.1(v1) 데이터는 첫 실행 때 자동 이관되며 이관 전 원본 전체를 `state['backup-before-v2']`에 보관합니다(상태 화면에서 내려받기/삭제).
백업 파일 형식은 0.1과 같은 `schemaVersion: 1` (사진 data URL 포함)이라 데스크톱 이전 원본으로 사용합니다.
